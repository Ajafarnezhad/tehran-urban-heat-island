تحلیل فضایی

همبستگی، شبکه‌بندی ۵۰۰ متری و Getis-Ord Gi*

گسیل‌مندی سطح
Pv = ((NDVI − 0.2) / 0.3)² ε = 0.966(1−Pv) + 0.973·Pv + 0.005

تخصیص گسیل‌مندی بر اساس سهم پوشش گیاهی هر پیکسل، به‌جای مقدار ثابت — دقت LST را در مناطق مخلوط شهری بهبود می‌دهد.

تصحیح تک‌کاناله
LST = T_B / (1 + (λ·T_B/ρ)·ln ε)

λ = 10.895µm (باند حرارتی TIRS)، ρ = 14388 µm·K (=h·c/k_B) — روش Artis & Carnahan (1982).

مقایسهٔ تک‌روزهٔ دو تاریخ برای برآورد روند بلندمدت گرمایش کافی نیست — نوسان جوی روزانه اثر آن را می‌پوشاند (تفاوت میانگین اینجا فقط ۰.۰۵ درجه است). آنچه این دو صحنه با اطمینان بالا نشان می‌دهند، رابطهٔ ساختاری مکانی بین پوشش گیاهی/ساخت‌وساز و دماست: همبستگی NDBI با LST برابر r = 0.55 (p < 10⁻²⁰⁰) در برابر r = −0.30 برای NDVI — یعنی تراکم ساخت‌وساز پیش‌بینی‌کنندهٔ قوی‌تری از دمای سطح نسبت به کمبود پوشش گیاهی است.

۰۴ — پیاده‌سازی

پشتهٔ فنی و ساختار مخزن

Google Earth Engine Microsoft Planetary Computer / STAC Python rasterio geopandas esda / libpysal scipy matplotlib · seaborn Jupyter

دو مسیر اجرا وجود دارد: پایپ‌لاین اصلی روی Google Earth Engine (هر AOI و بازهٔ دلخواه، نیازمند حساب GCP)، و مسیر دوم که بدون هیچ حساب کاربری مستقیماً همین دو صحنهٔ واقعی را از کاتالوگ عمومی Microsoft Planetary Computer می‌گیرد و نتایج بالا را بازتولید می‌کند.
